SSF Areekode Poster Generator — Prototype

Open index.html in a modern browser.

Features:
- Simple death-notice form
- 4 selectable Arabic calligraphy styles (prototype)
- Deceased person's name highlighted separately
- Funeral/prayer/ burial information is optional; its box disappears when disabled
- Post date is automatic by default
- Fixed footer: SSF AREEKODE + subtitle
- Cooper Black is requested for SSF AREEKODE, with browser fallback if the font is not installed
- PNG download and full-size preview
